# AgentPay / IOU Rails: Product Specification

## 1. Baseline Surface
Agent-to-agent payment system using IOU issuance and deferred settlement on Linea L2. Micro-fee accumulation (~0.0002 USD) with proof-carrying receipts.

## 2. Breakthrough 1: Proof-Carrying IOUs
Every IOU obligation carries the full execution proof (origin agent, dependency chain, sandbox evidence). Liability is machine-auditable before settlement.
- **Painkiller**: Eliminates manual verification and billing disputes in multi-agent swarms.
- **Proof Metric**: 100% auditable liability chain per transaction.

## 3. Breakthrough 2: Economic Intent Routing
The system predicts the cheapest trustworthy execution path across available agents and sandbox tiers, pricing the route in real time.
- **Category-Creating**: Dynamic, bid-based economic routing for agentic tasks.
- **Proof Metric**: < 10ms bidding latency.

## 4. Monetization Tiers
- **Agent**: Transaction micro-fees.
- **Node Provider**: Settlement hosting fees.
- **Enterprise**: $999/mo, Economic Routing Oracle + Full Audit Logs.
